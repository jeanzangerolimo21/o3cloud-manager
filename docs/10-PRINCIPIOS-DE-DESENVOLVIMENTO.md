# Princípios de Desenvolvimento

## O3Cloud Manager

1. O código deve ser simples antes de ser inteligente.

2. Toda regra de negócio pertence à camada Services.

3. Templates não executam lógica de negócio.

4. Nenhuma tela consulta APIs externas.

5. Toda sincronização gera histórico.

6. Toda alteração relevante gera auditoria.

7. O banco representa o domínio do negócio.

8. Sistemas externos permanecem donos de seus dados.

9. Relatórios são gerados exclusivamente a partir do banco local.

10. O objetivo do O3Cloud Manager é apoiar decisões gerenciais da Diretoria da O3Cloud.

# Antes de Escrever Código

Pergunte:

- Entendi completamente o problema?
- Estou na Sprint correta?
- Existe documentação relacionada?
- Existe código semelhante?
- Posso reutilizar?
- Estou alterando um componente homologado?
- Estou preservando a arquitetura?

Caso exista qualquer dúvida:

Pare.

Pergunte ao Product Owner.

Nunca assumir comportamento.

---

# Antes de Encerrar uma Tarefa

Executar obrigatoriamente:

✓ Checklist

✓ Definition of Done

✓ Revisão do Git Diff

✓ Atualização da documentação (quando aplicável)

✓ Homologação

Somente então iniciar a próxima tarefa.
